# PC Internet Cable

Marketing website for [pcinternetcable.com](https://pcinternetcable.com), operated by **Pasha Connects LLC**.

## Pages

- `/` — Home
- `/about` — About
- `/contact` — Contact & quote form
- `/live-agent` — Live agent / call options
- `/privacy-policy` — Privacy Policy
- `/terms-conditions` — Terms & Conditions
- `/reseller-disclosure` — Reseller Disclosure
- `/cookie-policy` — Cookie Policy
- `/fees-disclosures` — Fees & Disclosures

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

Deployed on Vercel. Framework preset should be **Next.js** with no custom Output Directory override.
