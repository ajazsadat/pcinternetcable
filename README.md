# PC Internet Cable

Marketing website for [pcinternetcable.com](https://pcinternetcable.com), operated by **Pasha Connects LLC**.

## Pages

- `/` — Home (includes AT&T provider information)
- `/about` — About / reseller disclosure
- `/contact` — Contact & quote form
- `/privacy-policy` — Privacy Policy

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Static export output is written to `out/`.
